BUSSID Mod Tuner

Change top speed, engine power, gears and handling in a vehicle mod. Your file is edited on your device and never uploaded.

1. Open the mod

No file chosen

2. Set the values

Choose a mod file and its current values appear here, ready to edit.

Leave a box as it is to keep the original value. Boxes with a blue edge are changed.

3. Save

The save dialog only allows certain file types, so the file arrives as name.bussidmod.txt. Rename it and delete the .txt at the end, then upload it to BUSSID. Keep your original file as a backup.
